# DEDALO collaboration contract

Read README.md and CONTINUIDAD.md first. Synthetic local research prototype, not a production security product.

- Run `python -m unittest discover -s tests -v` and `python -m dedalo.demo` after policy/HTTP changes.
- Loopback targets only. No external scanning, credentials or paid model calls by default.
- Never turn deterministic metrics into claims about LLM tokens or persuasion.
- Do not log credentials. Preserve source-session binding assigned by server.
- Keep budgets finite. Model output cannot modify permissions or execute arbitrary code.
- Separate branches and ownership; see COLABORACION.md.
- Document limitations and pre-event work honestly.
